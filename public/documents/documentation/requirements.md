# Requirements

## Overview
No prior experience is needed, but every student needs their own laptop. Media students need a stronger laptop because Blender 3D needs a 4-core processor and 16 GB of memory. Chromebooks and tablets do not work for either stream.

## Key Information
- No prior experience required
- Every student needs a Windows, Mac or Linux laptop with a USB port
- No Chromebooks, tablets or iPads
- No Windows in "S mode"; students must be allowed to install software
- Engineering Base: parents buy an Arduino Uno starter kit (about R800)
- Engineering Mid and High: the academy supplies the kit
- Media: no kit; a stronger laptop is needed
- Software is free (VS Code, Python, Git, Arduino IDE, Blender) and the academy provides its AI tools

## Common Questions
**Q: What laptop does my child need for Engineering?**
A: Windows 10/11 (64-bit), macOS 12+ or Ubuntu 22.04+; an Intel Core i3 8th gen, AMD Ryzen 3 3000 or Apple M1 processor; 8 GB memory; an SSD with 30 GB free; a webcam, Wi-Fi and a USB-A port or adapter.

**Q: What laptop does my child need for Media?**
A: Windows 10/11 (64-bit), an Apple Silicon Mac (M1 or newer) on macOS 13+, or Ubuntu 22.04+; a 4-core processor such as an Intel Core i5 8th gen, AMD Ryzen 5 3000 or Apple M1; 16 GB memory; graphics with 2 GB and OpenGL 4.3 (Intel UHD 620 or newer is enough); an SSD with 100 GB free; a 1920×1080 screen; a three-button mouse.

**Q: Can we use a Chromebook or tablet?**
A: No. Arduino, ESP32 and Blender don't run properly on them.

**Q: Can we use an older Intel Mac for Media?**
A: No. Blender 5 and later run only on Apple Silicon Macs.

**Q: What software do we need to buy?**
A: None. The software is free, and the academy provides the AI tools students use.

## Detailed Information

### Recommended laptop (both streams)
- Windows 11 or macOS 14+
- Core i7 / Ryzen 7, 8 cores
- 16–32 GB memory
- Dedicated graphics card with 4 GB or more
- 512 GB SSD

### Rules for parents
- Switch off Windows "S mode" before the first session
- Students must be able to install software; clone Arduino boards need a USB driver
- Media: check the processor has 4 cores. Some 8th-gen Core i3 chips have only 2.
- The webcam is used for AI vision projects; no student needs to buy a camera

### Laptop check
Every new student's laptop is checked in their first session. If it falls short, parents get a fix list before the second session.
